Gemini chat and ElevenLabs voice are now integrated into Lisa’s Windows test app.

1. Download **LISA.exe**, or use **Check for updates** in version 0.1.
2. Open **Settings → Chat & voice** and enter your Gemini and ElevenLabs keys locally.
3. **Test chat**, **Load voices**, choose Lisa’s voice, and **Preview voice**.
4. Click **Save & use AI**, then turn on **Lisa’s voice**. **Talk** records only when pressed; **Stop/Escape** interrupts.

Text conversation needs only Gemini. ElevenLabs powers speech and transcription; its same key can generate an optional cached UI chime. No OpenAI key is needed. API allowance and feature permissions depend on your accounts.

Your saved notes, optional history and settings survive updates. API keys are encrypted for your Windows account and are never included in this release. Free demo, four outfits and 36 illustrated poses remain available.

Validation: provider request/error contracts, encrypted key isolation, settings migration, voice audio format, GUI routing, interruption, all poses, microphone cleanup and Windows executable startup. Live API tests need your locally entered keys; the provided screenshots contain masked credentials. Character motion remains sprite-based breathing, blinking and audio-level mouth movement; a fully rigged model is a later visual upgrade.
